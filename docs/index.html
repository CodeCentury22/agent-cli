🤖 agent-cli

The modular, local AI coding agent ecosystem for developers.

Install on Linux / macOS
curl -fsSL https://raw.githubusercontent.com/CodeCentury22/agent-cli/main/install.sh | bash
Install on Windows (PowerShell)
irm https://raw.githubusercontent.com/CodeCentury22/agent-cli/main/install.ps1 | iex

⚡ Zero-Argument REPL

Run agent-cli anywhere in your workspace to launch an interactive session instantly.

🌐 Multi-LLM Gateway

Switch seamlessly between local Ollama models and cloud providers like Claude, Gemini, and OpenRouter.

🧠 Semantic Workspace Memory

Indexes your local codebase into ChromaDB using AST extraction and code chunking.
